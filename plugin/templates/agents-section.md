## Ratchet (verifiable development cycle)

This repo's harness lives in `.ratchet/`. It's generated by ratchet and owned by this repo. Work is done when it's verified, not when it looks done.

- `ratchet verify` checks what you changed against the base, per test: no test that passed before fails now, and new tests pass. `ratchet verify --full` before handing off.
- A test only proves your change if it fails without it: `ratchet proof f2p` checks this.
- Never weaken a check to pass: no skipped or deleted tests, no suppressions, no edits to `.ratchet/`, CI or snapshots in a feature task. Harness changes are their own reviewed tasks. `ratchet allow <id> --reason "..."` only when genuinely required.
- Log friction (slow checks, flaky tests, missing tools, unclear specs) with `ratchet blocker add "..."`.
- Multi-step work: `ratchet start "<goal>"` launches a coordinator thread in T3 Code (any harness). In an existing thread: `ratchet brief coordinator --goal "<goal>"`.
- How each product is run and exercised: `.ratchet/exercise/*.md`.
