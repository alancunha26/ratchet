# ratchet

Sets up an opinionated, verifiable development cycle inside a repo, using that project's own tools. Built on T3 Code and harness-agnostic.

Status: starting over. See [DESIGN.md](DESIGN.md) for the plan and [LESSONS.md](LESSONS.md) for what v0.1–v0.3 taught us. The previous implementation is archived on branch `archive/v0.3` (tag `v0.3.0-archive`).
